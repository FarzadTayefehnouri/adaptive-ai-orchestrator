# سند معماری سیستم چندعاملی تطبیق‌پذیر (System Architecture)

سامانه `adaptive-ai-orchestrator` بر اساس یک گراف وابستگی جهت‌دار (DAG) ماژولار طراحی شده است.

## ۱. چرخه حیات اجرای وظایف
۱. **تحلیل ورودی (Input Analysis):** تمایز بین PDF متنی و PDF اسکن‌شده تصویری.
۲. **طبقه‌بندی وظیفه:** تعیین پیچیدگی (Light, Moderate, Complex, Critical).
۳. **مسیریابی هوشمند سهمیه:** هدایت وظایف بر مبنای جدول سهمیه واقعی vs تخمینی و جابه‌جایی خودکار در زمان خطای ۴۲۹.
۴. **موتور بازیابی دوگانه:**
   - **بازیابی پسرو (Backward):** پیمایش معکوس روی گراف وابستگی برای شناسایی ریشه خطا.
   - **بازیابی پیشرو (Forward):** اجرای مجدد مرحله اصلاح‌شده و محاسبه مجدد صرفاً مراحل متأثر پایین‌دستی.
